Figure 2

The data choose the harmonic law, almost exactly

Treat the combination law as a power mean with free exponent q, so that C_mix = (Σ pᵢ Cᵢ^q)^(1/q). Harmonic is q = −1, geometric q = 0 and arithmetic q = +1. We estimate q from the mixes.

Figure 5

Boundedness: mixes stay inside their component range

Jensen's inequality orders the laws: harmonic ≤ geometric ≤ arithmetic, and all three lie between the smallest and the largest pure capacity. The plot shows where each mix lands inside the harmonic-to-arithmetic envelope: 0 is the harmonic prediction and 1 the arithmetic one.

Figure 6

Mix deviations are larger than repeat-to-repeat noise

This figure compares four sources of variation: re-running the same pure cell (σrep), how sharply the SLA flips from pass to fail (s), re-running the same mix design (σrun), and the departure of each mix design from the harmonic law (σmix). Repeated runs of a design share one design effect, so σmix is the real non-additivity and σrun is the instability of the measurement. Both use heavy-tailed (Student-t, ν = 4) distributions.

Figure 7

The burst factor is almost the same everywhere

The burst factor of a request class is B = MIT / MST: how many times its sustainable rate (30-minute MST test) a client can reach during a 2-minute burst (MIT test). SCALE prices requests with the sustainable capacity and keeps the instantaneous one as a safety threshold. Both price classes the same way only if B is the same for every class.

Frequentist tests

These tests use the log-ratio r = log(Cmix / Ĉlaw), averaged over the repeated runs of each mix design, so each design counts once (n = designs). TOST tests equivalence to zero within ±10 %, so a small p means the bias is practically negligible. The random-effects estimate (DerSimonian–Laird) weights each run by its measurement precision and reports the heterogeneity τ and I².

Method

How capacity and additivity were estimated

Data.

Capacity is latent. A run never observes its capacity C directly. It observes pass/fail verdicts of the SLA at the request rates (req/min) chosen by the doubling-then-bisection search, and the verdicts are noisy near the threshold: of the pure-cell runs end with a "largest pass" above the "smallest fail". The Bayesian model therefore uses every verdict through a logistic threshold likelihood, fitted in two stages ("cut"): stage 1 estimates the pure-cell capacities from pure runs only; stage 2 fits the mixes with those capacities fixed at their posterior means plus each mix's known prediction error. Without the cut, a few extreme mixes pull the shared pure-cell capacities away from their own data and the joint posterior becomes multimodal.

P(pass | r) = logistic( (θ_run − log r) / s_kind ) stage 1, pure run : θ = μ_cell + σ_rep,kind · z (day-to-day replicate noise) stage 2, mix run : θ = log M_q(p, e^μ̂) + se_pred · e + δ_model×kind + σ_mix,kind · u_design + σ_run,kind · z u_design, z ~ Student-t(ν = 4) (design effect shared by its repeats) M_q(p, C) = (Σ pᵢ Cᵢ^q)^(1/q) q = −1 harmonic · 0 geometric · +1 arithmetic δ_g = δ₀ + τ_δ · z_g ; μ ~ N(log 500, 3) ; σ ~ HalfN(0.3) ; s ~ LogN(log 0.05, 0.5) ; q ~ N(0, 2)

The uncertainty of each component capacity enters stage 2 through se_pred (delta method on the stage-1 posterior covariance). Proportions pᵢ are the realised request shares of each run, weighted by request counts. We fit four variants with NUTS (4 chains × 600 draws after 600 tuning steps; effective sample size ≥ 350 for every global parameter): harmonic, geometric and arithmetic with q fixed, and a free-q model. Longer runs occasionally let one chain drift into a distant region of the badly specified laws without changing the medians.

Comparing laws. Each law is scored by its posterior predictive log density for the pass/fail verdicts of every mix run. The run's own residual is integrated out, so a law cannot hide its misfit in it. The frequentist side uses the final search bracket [largest pass, smallest fail] (geometric midpoint) and replicate-averaged pure capacities. It adds a profile-likelihood interval for q with group offsets profiled out, and a calibration regression log Cobs = a + b·log ĈH.
