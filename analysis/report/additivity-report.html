Figure 2

The data choose the harmonic law, almost exactly

Treat the combination law as a power mean with free exponent q, so that C_mix = (Σ pᵢ Cᵢ^q)^(1/q). Harmonic is q = −1, geometric q = 0 and arithmetic q = +1. We estimate q from the mixes.

Figure 5

Boundedness: mixes stay inside their component range

Jensen's inequality orders the laws: harmonic ≤ geometric ≤ arithmetic, and all three lie between the smallest and the largest pure capacity. The plot shows where each mix lands inside the harmonic-to-arithmetic envelope: 0 is the harmonic prediction and 1 the arithmetic one.

Figure 6

Mix deviations are larger than run-to-run noise

This figure compares the scale of three noise sources: re-running the same pure cell on another day (σrep), how sharply the SLA flips from pass to fail (s), and the non-additive residual of each mix around the harmonic law (σmix). When σmix is larger than σrep, the mixes carry a real interaction effect beyond measurement noise.

Frequentist tests

These tests use the log-ratio r = log(Cmix / Ĉlaw) per mix run. TOST tests equivalence to zero within ±10 %, so a small p means the bias is practically negligible. The random-effects estimate (DerSimonian–Laird) weights each run by its measurement precision and reports the heterogeneity τ and I².

Method

How capacity and additivity were estimated

Data.

Capacity is latent. A run never observes its capacity C directly. It observes pass/fail verdicts of the SLA at the request rates (req/min) chosen by the doubling-then-bisection search, and the verdicts are noisy near the threshold: of the pure-cell runs end with a "largest pass" above the "smallest fail". The Bayesian model therefore uses every verdict through a logistic threshold likelihood:

P(pass | r) = logistic( (θ_run − log r) / s_kind ) pure run : θ = μ_cell + σ_rep,kind · z (day-to-day replicate noise) mix run : θ = log M_q(p, e^μ) + δ_model×kind + σ_mix,kind · z M_q(p, C) = (Σ pᵢ Cᵢ^q)^(1/q) q = −1 harmonic · 0 geometric · +1 arithmetic δ_g = δ₀ + τ_δ · z_g ; μ ~ N(log 500, 3) ; σ ~ HalfN(0.3) ; s ~ LogN(log 0.05, 0.5) ; q ~ N(0, 2)

Pure and mix runs are fitted jointly, so the uncertainty of each component capacity propagates into the prediction it feeds. Proportions pᵢ are the realised request shares of each run, weighted by request counts. We fit four variants with NUTS (4 chains × 1,500 draws after 1,500 tuning steps): harmonic, geometric and arithmetic with q fixed, and a free-q model.

Comparing laws. Each law is scored by its posterior predictive log density for the pass/fail verdicts of every mix run. The run's own residual is integrated out, so a law cannot hide its misfit in it. The frequentist side uses the final search bracket [largest pass, smallest fail] (geometric midpoint) and replicate-averaged pure capacities. It adds a profile-likelihood interval for q with group offsets profiled out, and a calibration regression log Cobs = a + b·log ĈH.
